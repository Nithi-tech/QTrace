Installing the APK: your phone will ask you to allow "install unknown apps" for whichever app opened the file (Chrome, Files, etc.) — that's expected since this isn't distributed via Google Play.

First load note: the backend runs on a free-tier server that sleeps after 15 minutes of inactivity. The first request after a quiet period can take 30–50s to wake up — this is normal.
